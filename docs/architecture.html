    How the router decides

    1 · Features for each question

    x = [ 384 MiniLM numbers, rule_score(q), min(words, 200) / 200 ] → 386 numbers

    2 · Logistic regression

    p_hard = 1 / (1 + e^-(w · x + b))

    The weights w and b were learned offline from labels.csv, where needs_large = 1 means the small model's answer was judged wrong.

    3 · Threshold

    p_hard ≥ t → large model p_hard < t → small model (t = 0.50, slider in the app)

    Cascade (alternative)

    Ask the small model first and have it rate its confidence from 1 to 10. Below 7, throw that answer away and ask the large model.

    Rule scores in the examples are computed exactly as router.py does. Similarities, p_hard values and costs are typical example values.
